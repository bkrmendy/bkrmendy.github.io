Every programmer eventually starts a blog, and most of them begin with a post
about the blog itself. This is that post. I'll keep it short.

## Why

Writing is thinking made slow enough to inspect. When I explain something in
prose I find the holes in my understanding much faster than when it lives only
in my head or in a pile of half-finished code.

So the plan is simple: write about things I'm working on, things I've
learned the hard way, and the occasional opinion I'm willing to defend.

## How it's built

The site is generated by [Astro](https://astro.build) from plain Markdown
files. There is no JavaScript shipped to your browser, no tracking, and no
comments section. Posts live in `src/content/posts/` and look like this:

```markdown
---
title: "Hello, world"
date: 2026-10-14
---

Every programmer eventually starts a blog...
```

Code gets syntax highlighting at build time:

```c
#include <stdio.h>

int main(void) {
    for (int i = 0; i < 3; i++)
        printf("hello, world %d\n", i);
    return 0;
}
```

> Simplicity is prerequisite for reliability. — Edsger W. Dijkstra

Everything is set in JetBrains Mono, because if I'm going to stare at text, it
might as well be text that looks like code.
